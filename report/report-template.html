1. O Problema: O Colapso das Janelas de 5 Horas

O desenvolvimento autônomo de código exige centenas de interações diárias com ferramentas de sistema (leitura de arquivos, compilações, execução de testes unitários). Quando concentrado em uma única ferramenta com plano de US$ 20 (notadamente o Claude Pro), o fluxo de trabalho inevitavelmente sofre o chamado Context Death Spiral: em sessões onde o histórico acumulado ultrapassa 80.000 tokens, o limite de requisições cai de ~45 mensagens para apenas 10 a 15 a cada 5 horas, paralisando a equipe em menos de 20 minutos de uso contínuo.

2. A Solução: Triangulação Simbiótica de 3 Assinaturas de Consumo

Em vez de recorrer a faturamentos de API por token (cujos custos frequentemente ultrapassam R$ 2.000/mês em rotinas de teste e refatoração pesadas), a arquitetura proposta unifica três planos de consumo fixo de ~US$ 20 através de ferramentas CLI locais e gerenciadores de fila:

1. EXPLORAÇÃO  : Gemini 3.8 Flash varre o projeto e gera resumo conciso em JSON (2k tokens).
2. ARQUITETURA : Claude Sonnet 5.5 lê o resumo e escreve a lógica core sem reenviar lixo.
3. TESTES      : Codex CLI é disparado em Git Worktree isolada e cria todos os testes unitários.
4. AUDITORIA   : Antigravity roda o Chromium, clica nos elementos e tira prints de evidência.
5. GATE FINAL  : Claude Opus avalia a prancha final e sanciona a entrega em turno único.
